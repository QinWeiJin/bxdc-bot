# Proposal: module2-file-upload（文件上传模块）

> 来源：[`需求方案A1.md`](file:///Users/zhangzhuang/ai/gitbbxdc-bot/bxdc-bot/%E9%9C%80%E6%B1%82%E6%96%B9%E6%A1%88A1.md)「模块二：文件上传（壮）」

## 动机

当前项目（`bxdc-bot`）在文件上传链路存在以下问题：

1. **三种上传方式**（图标点击、拖拽、`Ctrl+V` 粘贴）尚未在同一交互层完整落地，缺少统一的状态管理与上传取消能力。
2. **校验规则分散**：类型、大小、数量、重复四类校验在多处实现，行为不一致，提示文案与需求方案不符（如需求要求「单文件上限 10MB」「单会话最多 5 个」，与现状 `FILE_UPLOAD_CONFIG` 限额有差异）。
3. **重复校验**目前未真正生效，未做"上传时全量目录去重"。
4. **存储**未与用户隔离目录绑定（依赖模块一：用户隔离，本期不实现）。
5. **可访问性**（loading / 取消按钮 / 颜色变化）需求方案明确列出但目前缺失或分散。

## 目标

1. 在前端实现**统一的上传 composable**（`useFileUpload`），覆盖三种上传方式与四类校验。
2. 在 `FILE_UPLOAD_CONFIG` 中调整限额、扩展名校验集合，使其**与需求方案 A1 严格对齐**。
3. 在上传组件中实现**取消上传**与**loading / 颜色变化**两种交互效果。
4. **不**依赖后端：本期仅前端实现（解析、存储、隔离属于其他模块，本 change 不实现）。

## 影响范围

| 模块 | 影响 |
|------|------|
| `frontend/src/composables/useFileUpload.ts` | 新增（统一上传 composable） |
| `frontend/src/types/fileUpload.ts` | 修改：限额表（10MB / 5 个）、类型集合（+csv +py）、新增重复校验字段 |
| `frontend/src/components/MessageInput.vue`（或等价文件） | 修改：挂载 useFileUpload、添加上传按钮、绑定拖拽、绑定 `Ctrl+V` |
| `frontend/src/utils/fileParser.ts` | 兼容扩展：`.csv` / `.py` 暂走 txt 分支（占位） |
| 后端 | **无修改**（本期仅前端） |

## Non-Goals

- 不实现后端存储、不实现用户隔离目录
- 不实现 OCR / 图片识别
- 不实现文件管理、下载、删除（属于其他模块）
- 不实现"自然语言生成技能"等 MCP 工具（属于模块四）

## 依赖

- 需要既有 `parseDocument`（fileParser.ts）作为解析入口（已存在）
- 需要既有 `FILE_UPLOAD_CONFIG`（types/fileUpload.ts）作为限额依据（已存在，需调整）
