## MODIFIED Requirements

### Requirement: 初始欢迎语
系统 MUST 在用户首次进入聊天时展示一条欢迎语，从内置问好素材库中随机选取模板并匹配用户昵称和头像，同步立即展示。

#### Scenario: 生成欢迎语
- **WHEN** 用户首次进入聊天界面
- **AND** 聊天记录为空
- **THEN** 系统从内置问好素材库中随机选取一条模板
- **AND** 匹配用户昵称和头像 emoji 后生成欢迎语
- **AND** 将其同步显示在聊天界面中（无需等待异步操作）

#### Scenario: 欢迎语不依赖 LLM
- **WHEN** 生成欢迎语时
- **THEN** 系统不发起任何 LLM 调用
- **AND** 即使 LLM 服务不可用，欢迎语仍能正常展示
